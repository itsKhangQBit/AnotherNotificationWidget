# AnotherNotificationWidget
Why isn't there an alternative notifications applet?

#### ~~THIS IS IN ALPHA STAGE (WHICH MEANS I'M NOT DONE MAKING IT FUNCTIONAL YET).~~ YAY, BETA STAGE! THERE'S ONLY PLASMA 6 VERSION FOR NOW.
#### PLEASE INSTALL `plasma-workspace-dev` IN ORDER TO MAKE THE APPLET WORK, AS THIS PROJECT USES THE LIBRARY `NotificatonManager` TO READ AND CLEAR NOTIFICATIONS.

A(n) (less functional but more customization) alternative notification applet to KDE's one. Just made this for fun beause I personally think that KDE devs only made the system applet functional (which is great enough!) and couldn't make the interface better. Inspired from Windows 11.

**Features:**
- Nothing much
- Just a clock on the panel
- A notification system:
- Popup for reading notification history
- Toast "Popup" for new notifications.
- More toast info: - Popup for reading text, click to open
- - [Update 2.0a] Animations!
- - [Update 3.0b] Stacking & Image previews & Click to open is fixed & Link clicking is done!!
